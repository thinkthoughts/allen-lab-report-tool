# Grok Notebooks

This folder contains notebooks developed with Grok to prototype and demonstrate the **Residue Manifold Learning (RML) + CGCS** framework for the Allen Lab collaboration.

## Notebook Index

| Notebook | Purpose |
|---------|--------|
| `01_Introduction_to_RML_CGCS.ipynb` | Core concepts, standard CGCS, visualizations |
| `02_CGCS_Trisomy21_Prototype.ipynb` | Main prototype: Trisomy 21 dosage modeling |
| `03_Chr21_Residue_Encoding.ipynb` | DNA base-pairing → modular residue mapping |
| `04_Transcriptomic_Analysis.ipynb` | (Planned) Working with real RNA-seq data |
| `05_Intervention_Simulation.ipynb` | Modeling therapies as coherence recovery |
| `06_Person_to_Person_Variability.ipynb` | (Future) Individual differences |

## Purpose

These notebooks are designed to be:
- Easy to run in Google Colab
- Well-documented and educational
- Reproducible for the Allen Lab team
- Focused on turning abstract math into practical biological insights

**Development Note**: These notebooks were initially stubbed with Grok and will be iterated on together with ChatGPT as needed.
